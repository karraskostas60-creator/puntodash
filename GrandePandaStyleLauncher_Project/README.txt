Grande Panda-style concept launcher for Android head units
This is an original visual approximation, NOT Fiat's official software and not an exact copy.
It provides a landscape home screen with clock/date, weather placeholder, car-style center panel and shortcuts.
Navigation/music/phone/settings shortcuts launch available Android apps. Radio integration requires the head unit's proprietary radio app/API and is not implemented.
Open this folder in Android Studio, allow Gradle sync, then Build > Build APK(s).
Install the resulting app-debug.apk on the head unit. To use as Home, choose it in Android default Home app settings if the device allows it.
Target resolution is flexible; layout scales, but test on the actual BLG 463.
